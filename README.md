An interactive Excel Dashboard created to analyze Blinkit’s sales performance, outlet insights, item categories, and customer ratings.
This project demonstrates how Excel can be used as a powerful business intelligence tool for data-driven decision-making.

🔍 Project Overview

This dashboard provides a complete overview of Blinkit’s business by answering key questions such as:

How much total sales are generated?

Which outlet size and location perform best?

Which item categories drive the highest revenue?

How do ratings and average sales vary across outlets?

The focus is on clarity, interactivity, and actionable insights.
